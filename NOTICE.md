## Inspiration

The two roles in this project, a pre-planning consultant named Metis and a spec
reviewer named Momus, were inspired by the agents of the same names in
**Oh-My-OpenAgent**, an open-source project for orchestrating coding agents.

Oh-My-OpenAgent is distributed under the Sustainable Use License 1.0. As we
read it, that licence permits free, non-commercial distribution only and is
non-sublicensable, so it is not compatible with this project's MIT licence.
For that reason:

- **No text or code from Oh-My-OpenAgent is included here.** The prompts
  (`tools/metis/prompt.md`, `tools/momus/prompt.md`) were written from scratch
  from plain-language descriptions of each role.
- This project is not affiliated with, endorsed by or derived from
  Oh-My-OpenAgent. It credits it as inspiration only.
- If you want the original agents, get them from their authors, under their
  licence.

## Names

Metis and Momus are figures from Greek myth: Metis, counsel and prudence;
Momus, the god of fault-finding. The names are used here only as labels.

## Third-party code

None. The tools use only the Python standard library, and nothing is bundled
from other projects.

## Contributing

Anyone who contributes prompts must write them from a role description, not
from another project's prompt text, and must be able to say so. See
`AGENTS.md`.
